##  Portal Halloween 
# Um site criado sobre series, filmes de halloween

# Tecnologias utilizadas
Neste pequeno site usamos:
Html
Git
GitHub

# Estrutura dos arquivos
Index.html Pagina inicial do portal
Features Criadas para separar etapas e códigos na hora de criar sem poluir

# Como abrir o portal
Baixe os arquivos do github no seu computador local, abra o vs code, ou até mesmo dentro da pasta, dois cliques na INDEX.HTML

## Descrição das branches
Main: Principal, onde todo o serviço roda
Develop: Dada para criação e organização de todas as outras branches
Feature/Series: Onde o código das series foi criado e organizado
Feature/Cadastro: separada somente para cadastro e login do usuario
Fix/correção: Feita para corrigir conflitos ou bugs do sistema

# Estratégia dos pull requests
juntei todas as branches primeiramente na develop, e depois disso, me certificando de que nao ha nenhum conflito eu fiz o pull request para a Main
